# Termux.io.vn

A small static blog of illustrated Vietnamese stories. Posts come from
[`pwterm story <url>`](https://github.com/dhhieu113pro/pwterm), which stores
each story in `~/.pwterm/stories/stories.sqlite` with its images in
`~/.pwterm/stories/<slug>/`.

## Publish new stories

```bash
node scripts/sync.js
git add -A && git commit -m "posts: sync stories" && git push
```

The pwterm database is the source of truth. `index.html`, `posts/`, and
`assets/img/` are generated by the sync script — don't edit them by hand.
GitHub Pages serves the repo root at <https://dhhieu113pro.github.io/>.

## Develop

```bash
node --test scripts/sync.test.js
node scripts/sync.js --db /path/to/stories.sqlite --out /path/to/output
```
