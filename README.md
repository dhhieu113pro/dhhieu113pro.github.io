# Termux.io.vn

A small static blog of illustrated Vietnamese stories. Posts come from
[`pwterm story <url>`](https://github.com/dhhieu113pro/pwterm), which stores
each story in `~/.pwterm/stories/stories.sqlite` with its images in
`~/.pwterm/stories/<slug>/`.

## Publish new stories

```bash
git clone https://github.com/dhhieu113pro/dhhieu113pro.github.io.git
cd dhhieu113pro.github.io
node scripts/sync.js
git add -A && git commit -m "posts: sync stories" && git push
```

Post pages use a swipeable card reader: each story part is a card with the
illustration on top and text below. Swipe, the arrow buttons, the dots, and
the left/right arrow keys all move between parts; without JavaScript the
cards simply stack vertically. Cover and card images show a shimmer skeleton
while they load, and a small ↓ badge marks parts whose text scrolls. Text has
a comfortable 62-character measure with each sentence on its own line. Dots float over the bottom of the card;
a "Tiếp theo" bar opens the next story. On phones the post fills the screen:
a top bar has the back arrow, title and counter, and pinch/double-tap zoom is
disabled on post pages.

The home page is a full-screen cover feed (no site header or footer) — swipe
up/down through covers, tap "Đọc ngay" to open the reader, or use the arrow
keys / next button.

The pwterm database is the source of truth. `index.html`, `posts/`, and
`assets/img/` are generated by the sync script — don't edit them by hand.

## Topics, branding and metadata

`/tam-su/` is a generated topic index. It groups stories by keywords in
`TOPICS` in `scripts/sync.js` (title + lead, first match wins, unmatched →
`Chuyện khác`); no editing is needed when a new story is published. Both the
post header nav and the home top bar link to it.

`assets/logo.png` and root `favicon.ico` are the site mark. The logo is used
in the header and home top bar; `favicon.ico` is intentionally not cache-busted
(browsers cache favicons aggressively). `logo.png` is included in
`assetVersion()` so changing it updates every `?v=` URL. Every page also emits
a `description` (posts use the story's `lead`), a favicon link, and an
`og:image` pointing at the absolute logo URL.
GitHub Pages serves the repo root at <https://dhhieu113pro.github.io/>.

## Listen mode

Each sentence can be spoken by a pre-generated MP3. Build the audio after
syncing stories (this runs the local VieNeu TTS and needs ffmpeg):

```bash
node scripts/audio.js
```

It writes `assets/audio/<slug>/NNN.mp3` plus a `.text` hash. `sync.js` links a
`data-audio` file only when that hash matches the current text, so a changed
story never points at stale audio — rerun `audio.js` and `sync.js` together.

The voice follows the narrator's gender (F → `doan_trang`, M → `duc_tri`). To
override one story, add it to `scripts/listen-overrides.json` keyed by slug:

```json
{ "a-story-slug": { "gender": "F", "voice": "kim_thanh" } }
```

Both keys are optional; `voice` wins over `gender`.

## Develop

```bash
node --test scripts/sync.test.js
node scripts/sync.js --db /path/to/stories.sqlite --out /path/to/output
```

## Theme

The top bar on every page has a theme button that cycles **Sáng → Tối → Tự
động**. Auto follows the device colour scheme (an OS sunset schedule drives it).
The choice is stored in `localStorage` under `blog-theme` and applied by an
inline head script before the stylesheet loads, so there is no flash.
