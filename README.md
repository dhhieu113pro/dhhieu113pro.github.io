# Termux.io.vn

A small static blog of illustrated Vietnamese stories. Posts come from
[`pwterm story <url>`](https://github.com/dhhieu113pro/pwterm), which stores
each story in `~/.pwterm/stories/stories.sqlite` with its images in
`~/.pwterm/stories/<slug>/`.

## Publish new stories

```bash
git clone https://github.com/dhhieu113pro/dhhieu113pro.github.io.git
cd dhhieu113pro.github.io
node scripts/sync.js
git add -A && git commit -m "posts: sync stories" && git push
```

Post pages use a swipeable card reader: each story part is a card with the
illustration on top and text below. Swipe, the arrow buttons, the dots, and
the left/right arrow keys all move between parts; without JavaScript the
cards simply stack vertically. Text has a comfortable 62-character measure
with each sentence on its own line. Dots float over the bottom of the card;
a "Tiếp theo" bar opens the next story. On phones the post fills the screen:
a top bar has the back arrow, title and counter, and pinch/double-tap zoom is
disabled on post pages.

The home page is a full-screen cover feed (no site header or footer) — swipe
up/down through covers, tap "Đọc ngay" to open the reader, or use the arrow
keys / next button.

The pwterm database is the source of truth. `index.html`, `posts/`, and
`assets/img/` are generated by the sync script — don't edit them by hand.
GitHub Pages serves the repo root at <https://dhhieu113pro.github.io/>.

## Develop

```bash
node --test scripts/sync.test.js
node scripts/sync.js --db /path/to/stories.sqlite --out /path/to/output
```
